looot provides a unified API marketplace that gives agents a single key and prepaid balance to access over 2,350 endpoints from 76 data providers. It offers a platform API (OpenAPI 3.1 with 261 paths) including a public catalog, and an MCP for bearer‑authenticated access. The service integrates with major AI assistants like Claude, Cursor, Codex, and ChatGPT, enabling tasks such as LinkedIn profile lookup, email discovery, SEO ranking, and social media trend analysis. Pricing is usage‑based, and documentation is available at docs.looot.ai.

**Areas:** Marketplace · Artificial Intelligence · Data · Integration

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for looot: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
